<div class="sec "><p class="kicker">Two methods</p><h2>Every system can be solved two ways</h2><div class="cards2"><div class="card" v-click><p class="num">1</p><h3>Substitution</h3><p class="txt2">Isolate one variable in one equation, then plug that expression into the other. Best when a variable is already alone, like <i>y</i> = 4<i>x</i> − 13.</p></div><div class="card" v-click><p class="num">2</p><h3>Elimination</h3><p class="txt2">Add or subtract the equations, scaling first if needed, so one variable cancels. Best when the coefficients already match or are opposites.</p></div></div><p class="foot" v-click>Either method always works. Pick the one that takes fewer steps for the system in front of you.</p></div>
